# Bundled fonts

These `.woff2` files are third-party and are **not** covered by this project's
MIT licence. They are redistributed here under the
[SIL Open Font License 1.1](https://openfontlicense.org/), which permits
bundling and redistribution with or without modification.

They are self-hosted rather than loaded from a CDN so the game renders
correctly offline as an installed PWA.

| File | Family | Retrieved from |
|---|---|---|
| `bigshoulders-800.woff2` | Big Shoulders Display | [Google Fonts](https://fonts.google.com/specimen/Big+Shoulders+Display) |
| `barlow-400.woff2` | Barlow | [Google Fonts](https://fonts.google.com/specimen/Barlow) |
| `barlow-600.woff2` | Barlow | [Google Fonts](https://fonts.google.com/specimen/Barlow) |
| `plexmono-500.woff2` | IBM Plex Mono | [Google Fonts](https://fonts.google.com/specimen/IBM+Plex+Mono) |

Each file is the Latin subset only. The full licence text and authorship for
each family is available on its Google Fonts page linked above.
